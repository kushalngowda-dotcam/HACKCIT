# DisasterX AI

A React + Vite emergency response simulation dashboard for disaster coordination, AI-assisted decision support, and responder operations.

## Features
- Command center dashboard for live incidents and coordination
- AI risk assessment and uncertainty views
- Resource allocation and hospital stress simulation
- Evacuation planning and crisis mode flow
- Citizen and responder portals

## Prerequisites
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, typically:
```bash
http://localhost:5173/
```

## Production build
```bash
npm run build
```

## Preview production build
```bash
npm run preview -- --host
```
